# 🤖 My IA Assistant

A powerful Python-based AI assistant with multiple personalities and intelligent features.

## 🚀 Features
- **5 AI Personalities**: Assistant, Creative, Expert, Friendly, Coder
- **Project Planning**: Tech, Business, Creative, Learning projects
- **Code Generation**: Python examples and help
- **Smart Calculator**: Math calculations
- **Entertainment**: Jokes, facts, quotes, stories
- **Conversation History**: Remembers your chat

## 📦 Installation
```bash
# Clone repository
git clone https://github.com/Humbulan/My-IA-Assistant.git

# Run the assistant
cd My-IA-Assistant
python ai_assistant.py
